# R8: Projections And Publication

**Status:** planned.

## Objective

Implement replacement status, export, and site projections with metadata-only
publication by default.

## Deliverables

- Status and citations projections with complete group and handle tallies.
- Deterministic export files.
- Metadata-only MkDocs publication projection.
- Projection regeneration after mutation or reconciliation.

## Acceptance

- Metadata-only mode exposes no accepted evidence text.
- Export is deterministic across repeated generation.
- Publication failure does not invalidate committed authority.
